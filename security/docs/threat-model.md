# Mini threat model — index41

## Scope

Публичный учебный кейс `Ростелеком ИТ — система обучения`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — Секреты / CI / цепочка поставки

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | Секрет в Git | Токен/ключ случайно попадает в коммит | Secret scan + .env вне Git |
| T2 | Избыточные права CI | Workflow имеет write там, где достаточно read | Минимальные permissions |
| T3 | Непроверенная зависимость | Пакет добавлен без инвентаризации | Dependency inventory + lockfile review |
| T4 | Опасный внешний action | Action подключён по плавающему тегу | Закреплять версии/commit для production-подхода |
| T5 | Артефакт не соответствует исходникам | Публикуется непроверенная сборка | Quality gate перед release |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
